# مشروع وَنَس — النسخة التجريبية 0.1

## الموجود حالياً
- واجهة عربية RTL بتصميم بنفسجي وذهبي.
- الرئيسية، الأصدقاء، الغرف، المحادثات، الملف الشخصي.
- تنقل بين الصفحات، بحث بسيط في قائمة الأصدقاء، وإرسال رسائل محلية داخل شاشة المحادثة.
- ملف تعريف PWA وأيقونة SVG وخدمة تخزين مؤقت أساسية.
- إعداد Capacitor مبدئي لتغليف المشروع كتطبيق Android.

## تشغيل سريع
افتح `www/index.html` في متصفح حديث، أو ارفع مجلد `www` على استضافة HTTPS لتثبيته كتطبيق ويب تقدمي (PWA).

## إنشاء APK باستخدام Capacitor
يتطلب ذلك جهاز كمبيوتر عليه Node.js وAndroid Studio وAndroid SDK:
1. افتح الطرفية داخل مجلد المشروع.
2. نفّذ: `npm install`
3. نفّذ: `npx cap add android`
4. نفّذ: `npx cap sync android`
5. نفّذ: `npx cap open android`
6. من Android Studio اختر Build ثم Build Bundle(s) / APK(s) ثم Build APK(s).

## مهم قبل النشر
هذه واجهة أولية وليست شبكة اجتماعية مكتملة. الحسابات، قواعد البيانات، الرسائل بين مستخدمين مختلفين، المكالمات الحقيقية، الغرف الصوتية، الإشعارات، والهدايا/المدفوعات تحتاج خادماً وخدمات موثوقة واختبارات وأماناً. لا تجمع بيانات حقيقية أو أموالاً في هذه النسخة التجريبية.

## بناء APK من الموبايل عبر GitHub Actions
1. ارفع ملفات المشروع إلى مستودع GitHub جديد، مع الحفاظ على مجلد `.github/workflows`.
2. افتح تبويب Actions في المستودع.
3. اختر Build Wanas Android APK ثم Run workflow.
4. بعد نجاح البناء افتح نتيجة التشغيل ونزّل Artifact باسم Wanas-debug-APK.
5. فك ضغط ملف Artifact ثم ثبّت ملف APK على هاتف أندرويد.

ملاحظة: هذا ينتج APK تجريبياً (debug) للتثبيت والاختبار، وليس إصداراً نهائياً موقّعاً للنشر على Google Play.
